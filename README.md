# प्रतिक आणि अंकिता: लग्नाचे आमंत्रण

> **खासगी रिपॉझिटरी. सर्व हक्क राखीव.**
> या रिपॉझिटरीतील कोड, डिझाइन, मजकूर आणि फोटो हे प्रतिक आणि अंकिता यांच्या विवाहासाठीचे वैयक्तिक साहित्य आहे. कृपया मालकांच्या लेखी परवानगीशिवाय यातील कोणताही भाग कॉपी करू नये, पुन्हा वापरू नये, इतरांना वाटू नये किंवा पुन्हा प्रकाशित करू नये.

दोन माणसं, एक मोठा दिवस, आणि त्याबद्दल सगळं सांगणारी एक वेबसाइट.

ही रिपॉझिटरी प्रतिक आणि अंकिता यांच्या लग्नाचे डिजिटल आमंत्रण सांभाळते. ही एक साधी स्टॅटिक साइट आहे, जी साध्या HTML, CSS आणि JavaScript मध्ये बनवली असून GitHub Pages वर मोफत होस्ट केली आहे. कोणतेही ॲप डाउनलोड करायला नको, कागद हरवण्याची चिंता नको. फक्त लिंक उघडा, आणि आनंदोत्सव तुमच्यासमोर हजर.

## आमंत्रणात तुम्हाला काय दिसेल

* **आमची गोष्ट:** आम्ही इथवर कसे पोहोचलो, याकडे एक छोटीशी नजर
* **समारंभ:** प्रत्येक कार्यक्रमाच्या तारखा, वेळा आणि ठिकाणे
* **कसे पोहोचाल:** ठिकाणाची माहिती आणि मार्गदर्शन
* **RSVP:** तुम्ही येणार आहात हे आम्हाला कळवण्याचा सोपा मार्ग
* **छोट्या छोट्या गोष्टी:** पोशाखाच्या कल्पना, राहण्याच्या सूचना आणि नेहमी विचारले जाणारे प्रश्न

## कॉपीराइट आणि परवानग्या

ही एक खासगी रिपॉझिटरी आहे आणि तिचा मजकूर ओपन सोर्स नाही. मालकांच्या पूर्व लेखी परवानगीशिवाय कोड, डिझाइन, शब्दरचना किंवा चित्रे यांपैकी कोणताही भाग, पूर्ण किंवा अंशतः, कॉपी करण्याचा, बदलण्याचा, इतरत्र होस्ट करण्याचा किंवा पुन्हा वापरण्याचा कोणताही परवाना (licence) दिलेला नाही. या प्रकल्पातील काही वापरायचे असल्यास, कृपया आधी आम्हाला विचारा.

## गोपनीयतेबद्दल

हे आमंत्रण कुटुंबीय आणि मित्रमंडळींसाठी आहे. कृपया ही लिंक सार्वजनिकरीत्या पुढे पाठवू नका, आणि आमच्या परवानगीशिवाय कार्यक्रमाची माहिती किंवा पाहुण्यांची माहिती सोशल मीडियावर टाकू नका.
